# Project provenance and local contributions

Agent Skill Mastery Engine, formerly Askesis, is informed by the method in:

Tang, L.; Rashtchian, C.; Ferng, C.-S.; Tomkins, A.; Juan, D.-C.; Vu, T.
"WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution."
arXiv:2608.27454v1, 2026. The authors identify the paper as CC BY 4.0.

The retained paper method is listed in [references/paper-notes.md](references/paper-notes.md).
Paper facts and local architecture rules remain separately labelled.

## Locally authored architecture and algorithms

The following are local contributions in this implementation, not claims about what the
WikiSkill paper specifies:

- A runtime-neutral semantic core with measured, thin runtime adapters.
- Five-dimensional capability and isolation labels that cannot exceed recorded evidence.
- Sealed text-domain records, provenance markers, and train-only truth boundaries.
- A fresh confirmation gate after strict validation improvement.
- Intent-first, replayable transactions with fixed-clock crash-equality testing.
- A versioned dependency matrix with pre-intent read, tree, absence, and exact output-plan
  binding.
- Immutable skill snapshots, one authoritative active pointer, and a disposable mirror.
- Exclusive validated and approved-untested delivery routes with a durable ledger.
- Visibility-safe, reversible observation seeding before baseline evidence.
- Explicit, review-only Task Observer input and output bridges that preserve external
  ownership of live observation, confidence, clustering, and immediate skill authoring.
- Deterministic staged archives, public-claim evidence classes, and a binding/report-only
  Gate 2 comparator.
