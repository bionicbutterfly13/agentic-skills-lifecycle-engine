## Local implementation and experimental limits

ASME contributes a runtime-neutral core, explicit adapter capability records,
sealed text domains, transactional recovery, dependency binding, staged delivery,
and review-only observation bridges. Its second confirmation gate is a local
extension, not a WikiSkill requirement.

Preserving code and passing software tests do not establish model performance,
live Hermes isolation, or paper-comparable experiments. The inherited public-claims
policy accepts scripted fixture evidence in cases documented by the parity audit;
its labels must not be used as experimental proof.
